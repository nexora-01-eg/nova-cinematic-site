# NOVA / 01 — Cinematic Website

A premium experimental single-page website designed as a **living digital object**.

## Included
- Three.js + WebGL 3D object
- Unreal Bloom post-processing
- Lenis smooth scrolling
- GSAP entrance motion
- Custom cursor
- Scroll progress
- Responsive mobile layout
- Noise / film-grain layer
- No build step required

## Run
Open `index.html` in a modern browser.

For the best experience, serve the folder through a local static server, e.g. VS Code Live Server.
Internet access is required at runtime because the visual libraries are loaded from jsDelivr.
